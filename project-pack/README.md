# Project Pack

A static page that collects a website brief and downloads three files:

- `PROJECT.md`
- `AGENTS.md`
- `skills-install.txt`, which contains `npx skills add RamezHany/payload-cms-skills`

Open [index.html](index.html) in a browser. The page has no account and no server. Downloads use the browser only, so it works from a `file://` URL.

The `AGENTS.md` text in the page is a copy of [AGENTS.template.md](../skills/payload-project-kickoff/assets/AGENTS.template.md). When that template changes, update the copy in `index.html`.

The phase checklist matches the phases in the repository README.
