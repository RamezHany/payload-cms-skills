## Naming

| Thing | Convention | Example |
| --- | --- | --- |
| React component file | PascalCase | `BookingForm.tsx` |
| Hook | camelCase starting with `use` | `useAvailableSlots.ts` |
| Utility, lib, schema files | camelCase | `generatePreviewPath.ts` |
| Route segments | kebab-case | `exit-preview/` |
| Collection or global slug | kebab-case | `payment-events` |
| Collection or global folder | PascalCase | `PaymentEvents/` |
| Environment variable | SCREAMING_SNAKE_CASE; `NEXT_PUBLIC_` only for values safe in the browser | `NEXT_PUBLIC_SERVER_URL` |

## Where not to put things

- No business logic in `src/app/**/page.tsx`. Pages fetch data and compose sections.
- No Payload Local API calls in client components.
- No secrets in any file under `src/components` or any file with `'use client'`.
- No admin components inside `src/app`.
